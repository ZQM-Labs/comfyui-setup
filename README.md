# comfyui-setup

ComfyUI setup scripts — ZQM fork with FARGO branding.

## Overview

This repository contains setup and bootstrap scripts for deploying ComfyUI with custom ZQM/FARGO configurations. It is the companion setup layer for the [`comfy-custom`](https://github.com/ZQM-Computing/comfy-custom) repository, which holds the actual ComfyUI fork.

## Contents

- Bootstrap/install scripts for ComfyUI
- FARGO-branded default workflows and node presets
- Environment and dependency setup

## Related

- [`comfy-custom`](https://github.com/ZQM-Computing/comfy-custom) — ZQM ComfyUI fork with custom nodes
- [`hermes-agent`](https://github.com/ZQM-Computing/hermes-agent) — Agent that orchestrates ComfyUI tasks
